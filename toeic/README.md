# 730 JOURNEY

TOEIC 730点を目指す無料のブラウザ学習アプリ。外部ライブラリ・APIキー・有料サービスは不要です。

## 起動

リポジトリのルートで `python -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザで `/toeic/` を開きます。GitHub Pagesでも `toeic/index.html` をそのまま配信できます。

## 内容

- ご提供の `toeic.pdf` から英単語681語：日本語訳、発音、自己評価、PDF掲載番号
- PDFの順番で50語ずつ学ぶ14セット、未習得の50語、ランダム20語
- 文法24問：Part 5形式の4択、正誤判定、日本語解説
- リスニング14問：Part 2〜4形式、音声速度調整、スクリプト、日本語訳
- 今日の10問：単語4問、文法3問、リスニング3問
- 間違えた問題の復習、累計正答率、学習日数、ブラウザ内の履歴保存

文法・リスニング問題はオリジナルです。単語の出典は英語漬け.com「TOEIC出る順の英単語一覧（頻出732語）」を印刷したユーザー提供PDFです。実際の過去問の分析や転載は行っていません。写真問題、長文読解、200問模試は未収録で、現時点の教材だけで試験範囲全体を網羅するものではありません。

音声はWeb Speech APIを利用し、英語音声やネット接続の要否は端末に依存します。実機での音声品質は確認が必要です。音声合成による会話は単一の声で読み上げます。

履歴は端末・ブラウザ単位のlocalStorageに保存されます。サイトデータを削除すると消え、別端末には同期されません。

## 確認済み

Chromiumで10問コース、正誤表示、履歴保存・再読み込み、復習リスト、音声操作UI、スクリプト表示、390px幅の横はみ出しなし、JavaScript例外なしを確認。読み上げ音声の聴感とカメラ等の機能は検証対象外です。

## PDF単語の収録状況

元資料: https://www.eigo-duke.com/tango/TOEIC1-1000.html

19ページのPDFのうち単語表は1〜14ページ。日本語・英語を文字認識し、認識が曖昧な箇所を画像と照合しました。681語を原資料の番号順で収録しています。原資料の順位をそのまま示しており、当アプリによる頻度分析や難易度評価ではありません。

広告・白い覆いで見えない51語（No. 43〜45、98〜101、154〜157、210〜213、266〜269、322〜325、378〜381、434〜437、490〜493、546〜549、602〜605、658〜661、714〜717）は推測で追加していません。出典と未収録番号はアプリの単語画面でも確認できます。

学習上誤解を招く一部の訳には補足を付け、PDFの元の訳も表示できるようにしています。PDFに例文はないため、取り込み単語の例文は未収録です。発音は単語の読み上げです。

単語の学習IDは単語そのものに基づき、配列位置に依存しません。旧50語版の習得・復習履歴は同じ単語へ移行します。新単語集に含まれない旧単語は習得・復習リストから除き、累計解答数と日別履歴は保持します。

追加検証：全681語の意味表示・自己評価、14セット、未収録番号の表示、旧版履歴の移行と再読み込み、復習からの除外をChromiumで確認済み。
