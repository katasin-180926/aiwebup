# Our First Anniversary — 2026.11.27

## 公開手順
1. GitHub `katasin-180926/aiwebup` のルートにある `marker-ar.html` を、このファイルで置き換えます（既存の `index.html` はそのまま残してください）。
2. Commit changes を押して GitHub Pages の更新を待ちます。
3. https://katasin-180926.github.io/aiwebup/marker-ar.html を iPhone Safari / Android Chrome で開きます。
4. Hiroマーカー https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png を別画面に表示するか印刷してカメラを向けます。
5. 箱が現れたら「プレゼントを開ける」をタップします。

## 注意
- 端末のカメラ使用許可とHTTPSが必要です。
- Android/iPhoneでの実機テストはまだ実施していません。
- ARマーカーはQRコードとは別物です。QRはページを開くため、Hiroマーカーは3D表示位置の認識に使います。
- カップルキャラクターは仮のオリジナルデザインです。写真・服装などをもとに後から調整できます。
